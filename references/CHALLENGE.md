# Space Mission Design Game — Project Brief

This is a working summary of the NASA Space Apps Challenge brief. The official challenge description takes precedence if any details differ.

## Objective
Create an interactive educational game in which players design, manage, and simulate a space mission while learning about real mission-planning decisions and engineering trade-offs.

## Core Gameplay
1. Select a scientific mission objective.
2. Choose scientific instruments and spacecraft components.
3. Design a spacecraft within constraints such as mass, budget, power, and data capacity.
4. Select a suitable launch and orbit.
5. Simulate mission operations and observe consequences of design decisions.
6. Receive understandable feedback about mission performance.
7. Revise the design and attempt to improve the outcome.

## Initial Scenario
Earth-observation CubeSat mission.

## Engineering Mechanics
- Spacecraft mass and launch limits
- Mission budget
- Solar power generation and consumption
- Battery storage and eclipse operations
- Scientific data generation
- Communications and data downlink
- Orbit-dependent science opportunities
- Mission reliability and performance

The simulation must show meaningful relationships between engineering decisions. Use published facts where available and label illustrative numerical assumptions clearly.

## Optional Features
- Additional mission scenarios
- Random mission events
- Comparison of alternative spacecraft designs
- Visual orbit and mission displays
- Collaborative or multiplayer gameplay
- Leaderboards

Optional features must not delay completion of a functional single-player game.

## Project Priorities
1. A complete, playable mission-design loop
2. Credible engineering trade-offs
3. Clear educational feedback
4. Reliable, accessible web experience
5. Visual polish and optional features

## Development Constraints
- React, TypeScript, and Vite
- Browser-based, no login required
- No backend or database needed for the initial version
- Original visuals without unauthorized NASA branding
- Document NASA sources and AI-assisted development

## Important
Do not mistake a polished dashboard for a complete game. The player must be able to make decisions, simulate a mission, understand the results, and redesign the spacecraft.
