# NASA Space Apps Challenge — Submission Requirements

This checklist summarizes the submission instructions provided to the team. Verify all details against the official submission portal before submitting.

## Required Deliverables

1. Project name.
2. Project summary between 50 and 200 words.
3. Publicly accessible project link, with no login required.
4. Demonstration: a video no longer than 30 seconds OR a slide deck with no more than 7 slides. Provide a public link that does not require login. This is required for Global Award eligibility.
5. Project details explaining:
   - What the game does and how it works
   - The problem it addresses and its educational impact
   - Technologies and tools used
   - Creative decisions and engineering approach
6. NASA resources used, with exact names and URLs, and an explanation of how they materially contributed to the project.
7. Any other space-agency or third-party resources used, including relevant permissions and attribution.
8. AI / Super Intelligence (SI) disclosure:
   - Acknowledge AI-assisted code and data development.
   - AI-generated images and videos require a visible SI-generated watermark.
   - AI-generated audio requires acknowledgment in text or metadata.
   - Do not use AI-generated content that incorporates or modifies NASA branding, logos, flags, or mission identifiers.

## Final Verification

- The deployed game opens without login.
- The main game loop works from start to finish.
- The demo link opens publicly and meets the length/slide limit.
- NASA sources are correctly attributed.
- AI usage is disclosed.
- The project description accurately reflects what was built.
- All submission links are tested before the deadline.

Do not claim that a feature exists unless it is implemented and tested.
